# COVID-19 and excess mortality among children and young people in the US, 2020–2023

Reproducible code and data for

> Eilerts-Spinelli H, Acosta E, Liu L. *COVID-19 deaths and excess mortality among children and young people (ages 0–24) in the United States, 2020–2023: variation by age, state, region and race/ethnicity.* (working paper)

Everything in the paper — five figures, two appendix tables, the numbers quoted in the Results and the sensitivity analyses — is produced from the CDC WONDER exports in `data_input/` by ten R scripts run in sequence.

## Quick start

```r
# in R, from the project root (open us_youth_pandemic_mortality.Rproj)
renv::restore()        # installs the package versions in renv.lock (first time only)
source("run_all.R")    # ~1 minute
```

or from a shell: `Rscript run_all.R`. On the first run script 06 downloads the US state boundaries from the Census Bureau (via `tigris`) and caches them in `data_inter/us_states_cb_2022.rds`; every later run is offline.

Developed with R 4.6.1 on Windows; package versions are pinned in `renv.lock`.

## Data

All inputs are public CDC WONDER exports (tab-separated `.txt`, each with WONDER's query footer kept intact), queried between 4 June and 5 August 2024. See [`data_input/README.md`](data_input/README.md) for the query parameters of every file and [`data_input/wonder_queries.csv`](data_input/wonder_queries.csv) for a machine-readable index.

- **Deaths** — *Provisional Mortality Statistics, 2018 through Last Week* (2020–2023; 2023 was provisional at query time) and *Multiple Cause of Death, 1999–2020* (2010–2020, final). COVID-19 deaths are those with underlying cause ICD-10 U07.1.
- **Population** — *Single-Race Population Estimates 2020–2022* (by race/ethnicity and age) and *State Population Projections 2004–2030* (by state, sex and age).

WONDER suppresses counts below 10. Age-specific counts for states and race/ethnic groups are therefore recovered by querying open-ended age groups (all known ages, 1+, 5+, 10+, …), which are never suppressed, and differencing them (scripts 01–03).

## Methods in brief

- **Excess deaths** = observed − baseline, by calendar year 2020–2023. The baseline is a quasi-Poisson GLM, log-linear in year with a log-population offset, fitted to 2010–2019 and projected forward (`est_baseline_pi()` in `code/00_functions.R`). It is fitted separately for each US age group, each state × age group, each state for ages 0–24 combined, and each BEA region for ages 0–24 combined.
- **Intervals.** The scripts compute both a 95 % confidence interval of the baseline (`lc`, `uc`; ± 1.96 SE of the fitted value) and a 95 % prediction interval (`lp`, `up`; 200 draws of the coefficients from their sampling distribution, each combined with negative-binomial noise using the estimated dispersion; seed 2024). **The figures and tables show the prediction interval** (observed − `up`, observed − `lp`), which accounts for both the uncertainty of the fitted baseline and the Poisson-type variability of the observed counts. The CI is kept in `data_inter/` and shown alongside the PI in Figure S1.
- **Regions** follow the Bureau of Economic Analysis grouping (Table A1). Regional COVID-19 deaths and populations are sums over states; the regional baseline (and its interval) is fitted on the regional totals of deaths and population.
- **Relative risk** (Figure 4) = race/ethnicity-specific COVID-19 death rate ÷ all-races rate, same age group and year.
- **Sensitivity analyses** (script 10, Figure S1): US excess by age under six baseline specifications — fitting window 2010–2019 / 2014–2019 / 2015–2019 × log-linear trend / no trend — each with CI and PI; state 0–24 excess with the baseline fitted on the aggregate (main) vs. summed over the age-specific baselines; number of states with significant excess under CI vs. PI. Results in `output/sensitivity_summary.txt`.

## Methodological notes and known data issues

These are documented here so that they are not silently carried into the paper; see also `output/draft_check_2026-10-07.md`.

1. **Provisional 2023 data.** All 2023 death counts come from the provisional file as of July–August 2024; final 2023 data are now available on WONDER and would change counts slightly.
2. **Query drift.** The open-ended age queries for states were run on different days against the still-changing provisional file. For Arkansas, Nevada and Washington in 2023 the "1+" count exceeds the "known age" count by 1–2, which yields −1/−2 infant deaths (script 01 warns about this). Effect on 0–24 totals: ≤ 2 deaths.
3. **2023 populations by race/ethnicity** were not available at query time; 2022 values are carried forward (script 02).
4. **State denominators** are from WONDER's *State Population Projections 2004–2030* rather than postcensal estimates.
5. **Baseline specification matters at ages 20–24 and 0–1** (Figure S1). Mortality at 20–24 rose over 2010–2019, so the 2023 excess ranges from −1,533 (10-year log-linear trend, the main specification) to +1,335 (10-year mean) depending on the baseline; at 0–1 the declining infant mortality trend makes "no trend" baselines far too high. Ages 1–19 are robust to the choice.
6. **Zero cells.** Relative risks of 0 (no deaths) are omitted from Figure 4; rates of change with a zero denominator (infinite) or outside the axis range are dropped from Figure 5 (non-Hispanic Asian panel).

## Repository layout

```
code/              numbered scripts, run in order by run_all.R
data_input/        CDC WONDER exports (inputs) + README and query index
data_inter/        intermediate .rds produced by scripts 01–04 (+ cached state boundaries)
figures/           fig1 … fig5 and figS1 (.png) with their data (.csv)
tables/            Tables A1 and A2 (.docx and .csv)
output/            numbers quoted in the text; sensitivity summary; draft-check notes
renv.lock          pinned package versions
```

The repository's earlier content (a 2023 analysis of ICD-coded mortality microdata by race, 1999–2021) is preserved under the git tag `legacy-2023-microdata`.
